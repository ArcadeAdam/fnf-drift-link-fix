# FNF Drift link fix

Fixes a linked race problem where one car starts in the wrong place in **The Fast and the Furious Drift**.

**[Download the fix](https://github.com/ArcadeAdam/fnf-drift-link-fix/releases/latest/download/FNFDriftLinkFix.exe)**

Works on Windows 10 and 11. No Python or installation needed.

Your cabinets must already link and join the same race.

1. Close the game and launcher.
2. Open **FNFDriftLinkFix.exe**.
3. Click **Choose game file** and select your game's **sdaemon.exe**.
4. Click **Apply fix**.
5. Repeat on the other cabinet, then play.

**Fix is already installed** means you are done. The tool keeps a backup beside the game file. To go back, close the game and launcher, open the tool, choose the same file, and click **Undo fix**.
